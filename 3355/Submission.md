## 2. ความเข้าใจโจทย์ของฉัน

เขียนโจทย์ด้วยคำพูดของตนเอง

ให้อธิบาย input, output และ constraints สำคัญด้วย

ถ้ายังไม่เข้าใจโจทย์ทั้งหมด ให้เขียนสิ่งที่เข้าใจในตอนนี้ ความเข้าใจอาจยังไม่ครบหรืออาจผิดได้ แต่ต้องพยายามอธิบายอย่างจริงใจ

```text
รับ input มาใส่ไว้ในลิสต์ชื่อ mynum
โโยที่กำหนดเงื่อนไขแบ่งออกเป็น 2 อย่างคือ กรณีที่เลขเป็น -1 กับเลขที่ไม่ได้เป็น -1
โดยที่กรณีแรกคือ เลขไม่ได้เป็น -1 กำหนดให้ ถ้า input != -1 จะให้ใส่เลขไปใน mynum เรื่อยๆ โโยการใช้ while และถ้าเลขชเป็น -1 ให้เอาออกจาก list โดยใช้ .pop ได้เป็น
mynum = []
text = int(input())
if text != -1:
    mynum.append(text)
    while text != -1:
        text = int(input())
        mynum.append(text)
        if text == -1:
            mynum.pop()

หลังจากนั้น สร้างลิสต์สำหรับคำตอบขึ้นมาชื่อ result และกำหนด start กับ current มาดูว่าเลขมันต่อกันไหม เช่น 1-5 โดยที่ start กับ current จะมาจากตัวแรกของ mynum ได้เป็น
    result = []
    start = mynum[0]
    current = mynum[0]

หลังจากนั้นใช้ลูปวนเลขโดยเริ่มที่ 1 ดูว่าเลขตำแหน่งที่ 1 ของ mynum เท่ากับ current +1 ไหม เช่นในลิสต์มีเลข 1 2 3 4 5 ดูตำแหน่งที่ 1 ว่าเป็น 2 และ current +1  จากจึดเริ่มต้น คือ 0 เลข 1 ได้ 1+1 = 2 ถ้าใช่ ก็เปลี่ยนให้ current = mynum[i] หรือก็คือเปลี่ยนจาก 1 เป็น 2 ดูเลขต่อไปเรื่อยๆว่ามันต่อกันไหม
    for i in range(1, len(mynum)):
        if mynum[i] == current +1 :
            current = mynum[i]

ต่อมาเป็นกรณีที่เลขมันไม่ต่อกันเช่น 1 2 3 5 จะเห็นว่าเลข 5 ไม่ต่อจาก 3 ก็ให้ใส่เบลขเข้าไปในลิสต์เลยตรงๆ แต่ถ้าเลขมันต่อกันให้พิมพ์เป็น 1-3 ได้เป็น
        else:
            if start == current:
                result.append(str(start))
            else:
                result.append(f"{start}-{current}")
            start = mynum[i]
            current = mynum[i]

หลังจากนั้น ก็เอาค่าในลิสต์ที่ได้มาเขียนให้มันต่อกัน     print(", ".join(result))
และในกรณีที่ input เป็นเลข -1 ตั้งแต่ตัวแรก ให้พิมพ์  " " 
else:
    print(" ")

```

## 3. แผนแรกของฉัน

เขียนแผนแรกก่อนรับความช่วยเหลือจาก AI เพื่อน TA ผู้สอน หรือก่อนสรุป code สุดท้าย

ถ้าใช้ AI ให้เขียนแผนที่มีอยู่ก่อน prompt แรกที่ถาม AI

ถ้าถามเพื่อน TA หรือผู้สอน ให้เขียนแผนที่มีอยู่ก่อนถาม

ถ้าไม่ได้ใช้ AI และไม่ได้ขอความช่วยเหลือจากคน ให้เขียนแผนที่มีอยู่ก่อนหรือระหว่างเริ่มเขียน code

แผนนี้เขียนแบบคร่าว ๆ ได้ อาจยังไม่สมบูรณ์หรืออาจต่างจากวิธีสุดท้าย

สามารถเขียนเป็น pseudocode, flowchart idea หรือขั้นตอนความคิดได้

```text
รับ input 
คิดกรณีให้เลขที่ต่อกันและเลขที่ีไม่ต่อกับเลขอื่นใส่ในลิสต์
ปริ้นค่า
```

## 4. วิธีสุดท้ายที่ใช้จริง

อธิบายสั้น ๆ ว่า algorithm หรือวิธีสุดท้ายที่ใช้จริงใน code ที่ส่งคืออะไร

หัวข้อนี้ต่างจาก Section 3:

- Section 3 คือแผนแรกก่อนใช้ AI ก่อนรับความช่วยเหลือจากคน หรือก่อนเขียน code สุดท้าย
- Section 4 คือวิธีสุดท้ายที่ใช้ใน solution จริง
- ถ้าวิธีสุดท้ายเหมือนกับแผนแรก ให้เขียนว่าเหมือนกัน และอธิบายสั้น ๆ ว่าทำไม

ห้ามคัดลอกคำอธิบายจาก AI

ห้ามคัดลอกคำอธิบายจากคนอื่น
